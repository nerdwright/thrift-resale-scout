# Category packs

Load the pack that matches the item. Every pack uses the same six headings (ID cues · Fakes & repros · Value drivers · Value killers · Comps · Channel & ship), so Auction Scout and Listing Assistant can reuse them as is. Fees, comp labels, shipping-class costs, and buy rules are in `../core-pricing.md`; packs only say which applies.

| Pack | Load when the item is… |
| --- | --- |
| `wearables.md` | Clothing, shoes, hats, bags, belts, swimwear, kids' clothing, uniforms |
| `silver-metals.md` | Sterling, coin or 800 silver, silverplate, gold (not jewelry), pewter, brass, copper, flatware, hollowware |
| `watches-jewelry.md` | Watches, rings, necklaces, bracelets, brooches, costume jewelry, cufflinks |
| `art-prints.md` | Paintings, drawings, prints, posters, photographs, framed art |
| `ceramics-glass.md` | Pottery, porcelain, figurines, dinnerware, art glass, crystal, Depression and mid-century glass |
| `holiday-decor.md` | Christmas, Halloween, Easter, other seasonal decor; vintage decor and kitsch |
| `electronics-cameras-clocks.md` | Cameras, lenses, audio, game consoles, radios, small electronics, clocks |
| `household-cookware-tools.md` | Cookware, kitchen tools, small appliances, hand and power tools, outdoor and garden gear |
| `books-ephemera.md` | Books, magazines, comics, maps, postcards, records-adjacent paper, signed items |
| `asian-art-textiles.md` | Chinese, Japanese, Korean, and other Asian art and objects; robes, embroidery, rugs, quilts, vintage textiles |
| `furniture-local.md` | Furniture, mirrors, large lamps, anything heavy or bulky: local channel only |

Rules:

- One item, one pack. If two fit (a sterling-mounted glass vase), use the pack for the part that carries the value and mention the other.
- No pack fits: use the general workflow in `../identify.md`, Confidence Low, and say "no category pack".
- Packs give cues, not facts. Never state a maker, date, or value from a pack alone; a mark in the photo or a retrieved source has to show it.
