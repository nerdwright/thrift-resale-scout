PASS if the reply is a compact board with one numbered line per item (about 5 lines, one for each garment), each line naming the color and garment type, a verdict, and the photo numbers; a single "needs from you" style list for questions (such as the Ed Hardy size or whether the Curry jersey is adult or youth); and a running tally. Lines must not be long paragraphs.
FAIL if items are described in paragraphs, items are unnumbered, questions are scattered inside item descriptions instead of collected in one list, or there is no tally.
